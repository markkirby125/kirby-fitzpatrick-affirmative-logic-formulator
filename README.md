## Overview

The **Affirmative Logic Formulator** rewrites double negatives, hedging exclusions ("not uncommon"), and nested negative conditionals ("unless not") into clear, affirmative operational assertions across architecture docs, code comments, and PRs.

## Core Patterns

- **Double-Negative Elimination**: Replace "not uncommon" with "frequent".
- **Affirmative Guardrails**: State what is required or allowed rather than what is forbidden.
- **Conditional Normalization**: Eliminate "unless... not" logic puzzles.
